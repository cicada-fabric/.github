# CICADA

CICADA develops a Go system for authorized collaboration among native AI
sessions. Physical responsibilities are Hub, Node and Client; logical
participants are User, Control, Worker and optional Monitor. Explicit Join,
scoped grants and current server Guard preserve user authority.

- [Core repository and current dev documentation](https://github.com/cicada-fabric/cicada/tree/dev)
- [v0.1.x technical guide](https://github.com/cicada-fabric/cicada/blob/dev/docs/v01-technical-guide.md)
- [Android Client repository](https://github.com/cicada-fabric/cicada-client)
- [Contribution guidance](https://github.com/cicada-fabric/cicada/blob/dev/CONTRIBUTING.md)
- [Security reporting](https://github.com/cicada-fabric/cicada/blob/dev/SECURITY.md)

The current software is **0.0.1-dev**, unreleased, with product acceptance **PARTIAL**.
Development stays in 0.0.x until the user's actual deployment and acceptance,
then separate authorization for a main merge and initial 0.1.0 release;
larger v0.2.x designs remain planned. Native, Android,
physical-device and public HTTPS acceptance retain independent evidence.
First-party core material is Apache-2.0; third-party notices remain independent.
